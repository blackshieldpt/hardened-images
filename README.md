# hardened-images

Minimal, hardened OCI images built from [Wolfi](https://github.com/wolfi-dev/os)
with [apko](https://github.com/chainguard-dev/apko) and
[melange](https://github.com/chainguard-dev/melange): shell-less, non-root, no
package manager, with a software bill of materials, a blocking vulnerability
scan, keyless signatures, and SLSA build provenance — built and published
entirely on GitHub Actions.

## Images

Published to **`ghcr.io/blackshieldpt/<image>`**.

| Image | Tag |
|-------|-----|
| nginx | `ghcr.io/blackshieldpt/nginx:1.30` |

## What each image guarantees

- **Distroless & non-root** — no `/bin/sh`, no apk, runs as UID 65532.
- **SBOM** — CycloneDX + SPDX, attached as a cosign attestation.
- **Scanned** — Grype + Trivy gate the build at `SEVERITY_THRESHOLD`; exceptions
  are documented OpenVEX waivers, never a disabled scanner (see [`vex/`](vex/)).
- **Signed (keyless)** — cosign/Fulcio signature bound to this repo's workflow
  identity; no long-lived signing key exists.
- **SLSA build provenance (L3)** — generated by the GitHub Actions control plane
  via `actions/attest-build-provenance` and pushed to the registry.
- **Reproducible** — exact package set pinned in an apko lockfile;
  `SOURCE_DATE_EPOCH` set to the source commit.

## Consuming an image

Pull by **digest** (tags are mutable, re-pushed on each build):

```sh
docker pull ghcr.io/blackshieldpt/nginx:1.30
```

Verify the keyless signature and attestations:

```sh
IMAGE=ghcr.io/blackshieldpt/nginx:1.30
IDENTITY='https://github.com/blackshieldpt/hardened-images/.github/workflows/.*'
ISSUER='https://token.actions.githubusercontent.com'

cosign verify "$IMAGE" \
  --certificate-identity-regexp "$IDENTITY" \
  --certificate-oidc-issuer "$ISSUER"

cosign verify-attestation "$IMAGE" --type cyclonedx \
  --certificate-identity-regexp "$IDENTITY" --certificate-oidc-issuer "$ISSUER"

# SLSA L3 build provenance (GitHub attestation):
gh attestation verify "oci://$IMAGE" --owner blackshieldpt
```

## Building locally

Requires `docker apko melange cosign syft grype trivy jq` (see `make check-tools`).

```sh
make build  IMAGE=nginx   # apko build + lockfile + provenance
make test   IMAGE=nginx   # smoke test
make scan   IMAGE=nginx   # Grype + Trivy gate (honors vex/)
make sbom   IMAGE=nginx
```

Pushing, signing, and attestation happen in CI (`.github/workflows/build.yml`),
which holds the OIDC identity — there are no signing secrets to run locally.

## Adding an image

1. Add `images/<name>/apko/<name>.yaml` (and `images/<name>/melange.yaml` if you
   repackage upstream source) plus `images/<name>/test.sh`.
2. Set its tag (`VERSION_<name>`) in `config.env`.
3. Add `<name>` to the `IMAGES` list in the `Makefile` and the workflow matrix.

## Configuration

- `config.env` — registry, version pins, `SEVERITY_THRESHOLD`, `SCAN_GATE`
  (1 = block, 0 = advisory), and the keyless verify identity.
